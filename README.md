# 直播小助手 · EricWang 派生版

[English](README.en.md)

由 **EricWang** 开发维护的 Chrome 浏览器扩展，用于整合多个直播平台的关注列表，让您一站式查看关注主播的直播状态。

本项目基于 **Licardo（L1cardo）** 的 [Live-Assistant](https://github.com/L1cardo/Live-Assistant)，是独立维护的非官方 Fork。感谢原作者及所有上游贡献者开源代码。本派生版继续采用 **GPLv3**，保留原有署名和许可声明，详见 [来源与修改声明](NOTICE.md)。

当前版本：**1.3.4**。上游基点：`v1.3.3`（`8b282d1`）；修改日期：**2026-10-05**。

## 🌟 功能特性

- 打开弹窗或手动刷新时更新直播状态、观看人数或平台热度。
- 按平台逐步显示结果，较慢的平台不阻塞其他平台。
- 按平台保存上次成功结果，刷新失败或列表不完整时显示明确提示。
- 点击卡片打开直播间；点击星标立即收藏并置顶，无需重新请求关注列表。
- 自定义平台顺序、平台开关和悬浮按钮，支持跟随系统切换浅色/深色主题。
- 固定 720 × 600 弹窗、三列直播预览卡片。
- 直播列表下方提供默认收起、按需展开的两列未开播名单，支持打开直播间、收藏及查看有依据的上次直播记录。

## 📦 支持的平台

| 平台 | 直播列表与预览 | 未开播名单 |
|------|------|------|
| 斗鱼 | 关注列表分页、直播状态、热度、直播截图补充 | 复用关注分页中明确未开播的记录 |
| 虎牙 | 关注列表分页、直播状态、热度、平台返回的预览图 | 复用关注分页中明确未开播的记录 |
| B站 | 关注直播列表、观看人数、直播关键帧补充 | 展开名单时按需独立加载官方直播关注目录 |
| 抖音 | 关注列表、直播状态、观看人数、平台返回的预览图 | 暂无已验证的可靠来源 |
| Twitch | 关注直播列表、观看人数、直播预览图 | 暂无已验证的可靠来源 |

各平台接口依赖登录状态及平台服务；上述列表描述代码已实现的能力，不代表所有账号和接口始终可用。图片是平台提供的静态截图或封面，可能存在更新延迟。

## 🚀 安装与更新

### 安装本派生版

1. 在 [本仓库 Releases](https://github.com/Feeengyuuu/Live-Assistant/releases) 下载 `live-assistant-1.3.4.zip`。
2. 解压到一个长期保留的文件夹。
3. 打开 `chrome://extensions/`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压目录。

本派生版目前通过 GitHub 发布。原作者维护的 [Chrome 商店原版](https://chromewebstore.google.com/detail/gapakkgfjmmbdgaabgedecdhnpheboln) 和 [Edge 商店原版](https://microsoftedge.microsoft.com/addons/detail/iccpkamhcodiboccdihoimjaeoooflhk) 是上游产品，不包含本派生版的修改。

### 加载本地源码

1. 下载或克隆[本仓库的 enhanced 分支](https://github.com/Feeengyuuu/Live-Assistant/tree/enhanced)。
2. 打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目根目录。

更新已加载的本地扩展时，更新同一路径下的源码，再点击原扩展条目上的“重新加载”。继续使用原条目可保留其本地设置和收藏。扩展运行不需要 Node.js 或安装 npm 依赖。

## 🔧 使用方法

1. 先在需要使用的直播平台登录账号，再打开扩展弹窗。
2. 系统先显示本地缓存，再按需更新已启用平台；每个平台返回后立即更新其结果。
3. 点击主播卡片进入直播间，点击星标收藏主播。
4. 需要时点击直播列表下方的“未开播”标题展开名单。每次打开弹窗都默认收起；直播和未开播区域各自将收藏主播排在前面，共用同一收藏状态。
5. 点击“设置”，在两列面板中调整平台顺序、平台开关和悬浮按钮，再点击底部“保存并返回”生效。“取消”会丢弃本次未保存的更改。

“恢复默认设置”仅把当前草稿恢复为默认平台顺序、全部平台启用和默认悬浮导航，仍需保存后生效；收藏和关注列表缓存会保留。

成功结果在 60 秒内可复用；“刷新”会主动请求已启用的平台。未开播名单收起时只刷新主列表，展开时才刷新需要独立加载的辅助名单。网络故障或列表不完整时保留上次完整结果并标注状态；确认需要重新登录时清除该平台旧列表并显示登录入口。扩展通过打开弹窗和手动刷新获取更新，不持续轮询。

斗鱼预览优先补充直播间截图，B站优先使用直播关键帧；没有可用截图时显示封面，截图加载失败时回退到可用封面。界面说明见 [UI 使用指南](UI-UPGRADE-GUIDE.md)。

### 未开播与上次直播记录

为保持日常查看流畅，未开播名单默认收起，不记住上次展开状态；收起期间不会请求 B站辅助目录，也不会创建或重绘名单条目。展开后先使用已有数据，再按需补充 B站名单。斗鱼和虎牙的未开播数据复用主列表结果，无须额外请求。

未开播名单只收录平台明确报告未开播的主播；没有出现在直播列表、请求失败或尚未登录都不会被当作未开播。它覆盖当前支持的直播关注来源，不能代表所有平台的完整账号关注关系，也不会从汇总头像补造主播。B站独立请求保留最多 20 页、总计 10 秒的限制，较长名单可能只取得部分；失败或未完整获取时保留已有完整名单并提示，不为读完整个目录持续增加请求。成功的直播刷新不会把旧未开播名单标记为刚刚更新。

- **上次开播**：平台提供的有效开播时间，目前使用斗鱼的相关记录。
- **上次直播**：平台提供的有效直播记录时间，目前使用 B站的相关记录；不表示已确认的开播或结束时刻。
- **最近看到直播**：插件在完整成功刷新时曾看到该主播开播的本地时间，不能据此推断真实开播或下播时间。
- **暂无记录**：平台没有提供有效时间（包括返回空值或 0），插件也没有可用的本地观察；不会额外抓取大量直播间来推测历史。

时间按当前浏览器的当地时区显示。插件关闭期间不会继续记录开播历史；本地观察最多保存 1,000 位主播、180 天。具体数据来源和分页限制见 [接口核对记录](docs/offline-api-evidence.md)。

## 🧪 开发检查

项目使用原生 JavaScript、HTML/CSS 和 Chrome Extension API。开发检查需要 **Node.js 20 或以上版本**，在项目根目录运行：

```sh
npm run check
npm test
npm run package
```

这些命令无需先运行 `npm install`。`check` 验证语法与入口，`test` 运行回归用例，`package` 完成检查后生成 `dist/live-assistant-1.3.4.zip` 及 SHA-256 校验文件。发行包只包含明确列出的运行源码、图标、manifest、完整 LICENSE 和 NOTICE，不含本地备份或浏览器验收数据。可选浏览器测试使用 Playwright 和模拟数据，配置方法见 [贡献指南](CONTRIBUTING.md#开发和测试)。模拟测试通过不等同于所有平台真实账号验证通过。

## ⚠️ 数据与时效

设置、收藏、关注列表缓存和最近看到直播的观察记录保存在浏览器扩展的本地存储中；请求使用平台登录状态进行认证。直播和未开播名单分别记录获取状态及成功时间。保留的上次结果可能已过时，请留意平台状态和名单完整性提示。平台接口变化或限流可能影响数据获取。
