# 直播小助手 v1.3.4 — EricWang 派生版

本版本由 **EricWang** 开发维护，基于 **Licardo（L1cardo）** 的
[Live-Assistant](https://github.com/L1cardo/Live-Assistant) 开源项目。
感谢原作者及所有上游贡献者提供的代码基础。本版本为独立维护的非官方派生版，
继续使用 **GPLv3**，完整署名和修改说明见 [NOTICE.md](https://github.com/Feeengyuuu/Live-Assistant/blob/v1.3.4/NOTICE.md)。

修改日期：2026-10-05。上游基点：`v1.3.3`（`8b282d1`）。

## 改进

- 各平台独立显示加载结果，合并重复请求，防止旧响应覆盖新数据。
- 复用直播卡片和图片节点，保留滚动位置；收藏立即排序。
- 网络错误、未登录和不完整结果分别处理，失败不会冒充成功刷新。
- 斗鱼优先补充直播截图，B站优先使用直播关键帧；图片失败时保留回退。
- 设置页采用两列布局，保存和取消始终可见，恢复默认保留收藏。
- 未开播列表默认收起，只有展开后才加载辅助名单和渲染条目。
- 上次直播时间区分平台开播时间、平台记录和本地成功观察，缺失时如实显示暂无记录。
- 完善键盘操作、浅色/深色主题、回归测试及可复现打包。

## 安装

1. 下载本发布中的 `live-assistant-1.3.4.zip` 并解压到一个长期保留的文件夹。
2. 打开 Chrome 的 `chrome://extensions/`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中含 `manifest.json` 的解压目录。

已有本派生版的本地安装可更新原目录，并在原扩展条目点击重新加载，以保留其设置和收藏。
本发布是 GitHub 发行包；上游 Chrome / Edge 商店条目由原作者维护，不包含本派生版更新。

## 数据范围

各平台依赖自己的登录状态与接口可用性。未开播名单仅使用明确状态，B站补充查询有页数和时间上限；
较长名单会标明未完整。平台没有提供的历史时间不会额外逐房间抓取或推测。
